### 🚀 Проекты

* **[Skins-Marketplace](https://github.com/alonyaska/skins-marketplace)** — Маркетплейс игровых скинов. 
    * *Стек:* `Python (FastAPI)`, `PostgreSQL`, `Redis`, `Celery`, `Docker`.
    * **Реализованный функционал:** 
        * Спроектировал схему реляционной базы данных (PostgreSQL).
        * Настроил обработку фоновых и отложенных задач с использованием Celery и Redis.
        * Контейнеризировал сервисы приложения с помощью Docker для упрощения развертывания.

* **[FastCut](https://github.com/alonyaska/FastCut)** — Сервис для сокращения ссылок и управления контентом.
    * *Стек:* `Python (FastAPI)`, `Redis`, `Docker`.
    * **Реализованный функционал:** 
        * Разработал легковесный асинхронный API для генерации и редиректа коротких ссылок.
        * Использовал Redis в качестве хранилища типа ключ-значение для обеспечения высокой скорости отдачи данных.
        * Настроил изоляцию окружения через Docker-контейнеры.
